# Project Instructions

## Scope

These instructions apply to the entire repository. More specific `AGENTS.md`
files may add or override instructions within their directory trees.

Read `CLAUDE.md` before starting any task.

Treat the project conventions, architecture notes, coding standards,
and other instructions in `CLAUDE.md` as applicable to your work unless
they conflict with instructions in this file.

Before modifying code:
- Understand the existing implementation.
- Preserve existing behavior unless the task explicitly requires a change.
- Follow existing coding patterns and conventions.
- Run relevant tests or validation after making changes.

All Markdown files must begin with a top-level title followed immediately by a
`## Scope` section that states what the document covers.
